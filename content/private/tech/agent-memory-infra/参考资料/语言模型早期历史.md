
**技术演进**（简脉络）：

```
统计时代          → 深度学习早期      → BERT 时代          → 零样本时代
HMM/CRF+人工特征  → BiLSTM-CRF       → Token级分类+span   → GLiNER（标签描述匹配）
```

>**HMM（Hidden Markov Model，隐马尔可夫模型）**
    一种**统计序列模型**。核心思想：假设文本背后有一串"隐藏状态"（比如每个字属于人名/地名/普通词），这些状态按概率转移，每个状态按概率"发射"出我们看到的字。
   - 用在 NER 里：给每个字打标签（B-PER, I-PER, O...），通过统计学习转移概率和发射概率
   - 局限：**马尔可夫假设**——当前状态只依赖前一个状态，看不到更远的上下文

> **CRF（Conditional Random Field，条件随机场）**
    对 HMM 的升级。同样做序列标注，但它是**判别式模型**——直接建模"给定整个输入序列，输出标签序列的概率"，可以利用**全局特征**（前后文、词性、是否大写等人工设计的特征）。
- 在 NER 里的经典用法：手工设计大量特征 → CRF 学习特征权重 → 输出最优标签序列
- 后来演变为 BiLSTM-CRF、BERT-CRF 中的**解码层**——前面的神经网络提取特征，CRF 层负责保证输出序列合法（比如不会出现 I-PER 跟在 B-LOC 后面）

> **LSTM（Long Short-Term Memory，长短期记忆网络）**
    一种 RNN（循环神经网络）变体，专门解决**长距离依赖**问题。通过"门控机制"（遗忘门、输入门、输出门）控制信息的保留和丢弃。
- **BiLSTM-CRF** 是 2015-2018 年 NER 的标配架构：
    - BiLSTM（双向）负责编码上下文 → 每个位置得到一个特征向量
    - CRF 层负责解码出合法的标签序列
    - 被 BERT/Transformer 取代，因为 Transformer 的**注意力机制**能并行处理且捕获更长距离的依赖

**GLiNER 的做法**：不需要为每种实体类型训练专门模型。你传入一组**文本标签**（如 `["PERSON", "LOCATION", "APP"]`），模型在统一的语义空间中将文本 span 与标签进行匹配。这就是"零样本"的含义——不需要标注数据就能识别新类型。

**与传统分词的关系**：现代 Transformer 模型使用子词分词（BPE/SentencePiece），不需要显式中文分词步骤。AMS 实验中的"按标点切段"是**工程分段策略**，不是传统分词。

> **BPE（Byte Pair Encoding，字节对编码）**
    一种**子词分词算法**，不是模型，是**文本预处理方法**。
    工作原理：
    1. 初始词表 = 所有单个字符（或字节）
    2. 统计相邻 token 对出现频率，把最高频的合并为新 token
    3. 重复，直到词表达到目标大小
    举例：`"lower"` 可能被切成 `["low", "er"]`，而 `"lowest"` 切成 `["low", "est"]`
    **对中文的问题**：BPE 以字节为基础，一个中文字占 3 个 UTF-8 字节，可能被拆成无意义的字节碎片。==这就是报告中提到的"GLiNER 中文 span 边界错位"的根本原因——模型内部看到的 token 边界和字符边界对不上。==

## 关于 HMM 的阶数——你记得没错

你说的完全对。所谓"阶"就是**马尔可夫假设的阶数**——当前状态依赖前面几个状态：

| 阶数     | 含义                | 状态转移矩阵规模  |
| ------ | ----------------- | --------- |
| **一阶** | 当前状态只看**前 1 个**状态 | N × N     |
| **二阶** | 当前状态看**前 2 个**状态  | N × N × N |
| **三阶** | 看前 3 个            | N⁴        |

假设标签集大小 N=10（BIO 标注里很常见），那么：

- 一阶：10² = **100** 个转移参数
- 二阶：10³ = **1,000** 个
- 三阶：10⁴ = **10,000** 个

参数量是 **N 的指数增长**，而且每个参数都需要足够的训练数据来估计。二阶时数据稀疏问题就已经很严重了——大量三元组在训练集中根本没出现过，概率估不准。三阶基本不可用。

这正是《数学之美》里吴军讲的核心洞察：**理论上阶数越高越准，但实际上二阶/三阶就到头了**，因为：
1. **参数爆炸**：存储和计算都扛不住
2. **数据稀疏**：训练数据不够估计那么多参数
3. **收益递减**：从一阶到二阶提升明显，再往上提升很小

==这也是为什么后来大家转向 CRF（用特征工程绕开阶数限制）→ LSTM（用神经网络隐式捕获长距离依赖）→ Transformer（注意力机制，理论上每个位置直接看到所有其他位置），本质上都是在解决"**怎么在可承受的计算量内看到更远的上下文**"这个问题。==

## B-PER, I-PER, O —— BIO 标注体系

这是 NER 序列标注的**标签格式**，全称 **BIO 标注**：

| 标签 | 含义 | 例子 |
|------|------|------|
| **B**-XXX | Begin，某实体的**第一个**字 | "葛" → B-PER |
| **I**-XXX | Inside，某实体的**后续**字 | "瑞" → I-PER，"刚" → I-PER |
| **O** | Outside，**不属于**任何实体 | "借" → O，"了" → O |

实际标注效果（以"葛瑞刚借了10万"为例）：

```
葛   瑞   刚   借   了   10   万
B-PER I-PER I-PER O    O    B-MON  I-MON
```

模型的任务就是：给输入序列的每个字/token 预测一个这样的标签。CRF 层的作用就是保证输出**合法**——比如 `I-PER` 不能凭空出现，前面必须是 `B-PER` 或 `I-PER`。

还有扩展版 **BIOES**（加了 E=End 和 S=Single），标注更精确，但原理一样。
